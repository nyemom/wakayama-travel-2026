# Wakayama Road Trip 2026

## GitHub Pages 部署
1. 將 `index.html` 上傳到 GitHub Repository 根目錄。
2. Repository → Settings → Pages。
3. Source 選 `Deploy from a branch`。
4. Branch 選 `main`、資料夾選 `/(root)`，按 Save。
5. 等待部署完成，網站網址通常為 `https://帳號.github.io/Repository名稱/`。

## 更新網站
在 GitHub 開啟 `index.html`，點選鉛筆圖示編輯，完成後 Commit changes。GitHub Pages 會自動重新部署。
